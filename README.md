# 📚 Library Management System

A simple *Library Management System* developed in *C* that helps manage library records such as adding, searching, issuing, returning, and deleting books. This project demonstrates file handling, structures, functions, and menu-driven programming in C.

## 🚀 Features

- ➕ Add New Book
- 📖 Display All Books
- 🔍 Search Book
- 📝 Issue Book
- 🔄 Return Book
- ❌ Delete Book
- 💾 File Handling for Data Storage
- 📋 Menu-Driven Interface

## 🛠️ Technologies Used

- C Programming
- File Handling
- Structures
- Functions
- Arrays
